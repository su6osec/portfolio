Clash Display — self-hosted web fonts
=====================================

These two subsets (weights 600 and 700) are used by su6osec.vercel.app for
the hero name and the logotype only.

  Family   : Clash Display
  Foundry  : Indian Type Foundry (Fontshare)
  Source   : https://www.fontshare.com/fonts/clash-display
  License  : Fontshare Free Font License — https://www.fontshare.com/about-fontshare/fonts-license

They are self-hosted deliberately: no third-party origin, no CSP exception,
no render-blocking request, and the logo paints with the first paint of the
header.

If you redistribute the site, keep this notice alongside the .woff2 files.
